# WeChat Reader（微信读书 for Obsidian）

在 Obsidian 里登录微信读书、直接阅读书架上的书，并在旁边的 Obsidian 笔记里做笔记。

> 仅支持桌面版 Obsidian（依赖 Electron webview）。

## 功能

- **登录**：点击左侧 ribbon 的 📖 图标（或命令「打开微信读书」），在阅读器页面中点「登录」，用微信扫码。登录状态保存在插件专用的会话里，重启 Obsidian 不需要重新登录。
- **阅读**：阅读器就是微信读书网页版，书架、搜索、目录、翻页都和网页版一致。工具栏提供后退 / 前进 / 刷新 / 书架。
- **自动笔记**：打开一本书时，会在右侧分屏打开这本书的笔记（默认在 `WeChat Reader/书名.md`，不存在则自动创建，带书名、作者、封面等属性）。
- **同步划线与想法**：点击工具栏的 🔄（或命令「同步当前书的划线与想法」），把你在微信读书里的划线和想法按章节写入笔记的「划线与想法」区块。只替换 `<!-- weread:highlights:start/end -->` 之间的内容，你自己写的笔记不会被改动。
- **复制即摘录**：在阅读器中选中文字，点微信读书弹出的「复制」，文字会以 `> [!quote] 章节 · 时间` 的形式追加到笔记的「摘录」部分。如果没有生效，可以用命令「把剪贴板内容摘录到当前书笔记」。

## 设置

- 笔记文件夹（默认 `WeChat Reader`）
- 打开书时自动打开笔记（默认开启）
- 复制即摘录（默认开启）
- 退出登录

## 开发

```bash
npm install
npm test        # 单元测试
npm run build   # 生成 main.js
npm run dev     # 监听构建
```

把本目录（含 `manifest.json`、`main.js`、`styles.css`）链接或复制到 `<vault>/.obsidian/plugins/wechat-reader/`，然后在「第三方插件」里启用。

## 说明

- 插件只是在 Obsidian 里嵌入微信读书官方网页，登录走微信官方扫码流程，插件不接触账号密码。
- 划线同步使用微信读书网页版接口，章节 / 复制识别依赖网页版的页面结构；微信读书改版后可能需要更新插件。
